# Security and privacy

## Supported version

Only the current `main` branch is maintained. Archived notebooks and retired mechanism prototypes
are retained for research provenance, not as supported production software.

## Reporting a problem

Please report suspected credential exposure, path traversal, unsafe artifact loading, personal-data
exposure, or dependency vulnerabilities privately to the repository owner through GitHub's private
vulnerability-reporting feature when available. Do not open a public issue containing a secret,
account identifier, review text, raw record, or exploit payload.

The public repository must contain aggregate evidence only. Raw Steam data, user maps, per-user
metrics, and fitted user parameters are intentionally excluded.
